# Rhodium Rewards

A rewards management application that helps users track and manage their reward points and redemptions.

## Features

- **Rewards Tracking**: Monitor accumulated reward points
- **Redemption Management**: Redeem points for various rewards
- **User Dashboard**: View reward history and current balance
- **Promotional Banners**: Display active promotions and offers

## Getting Started

### Prerequisites

- Node.js 16+
- npm or yarn

### Installation

```bash
npm install
```

### Running the Project

```bash
npm start
```

## Development

```bash
npm run dev
```

## Building

```bash
npm run build
```
